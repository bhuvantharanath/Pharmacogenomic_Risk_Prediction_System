# B5 — Warfarin: VKORC1 and CYP4F2 — plan and pre-committed criteria

Written 2026-11-04 before any B5 code change.

## Facts that shape the design (checked before writing this plan)

- Part A A6 / F-14: PharmCAT 3.4.0 calls VKORC1 and CYP4F2 (e.g. `rs9923231 variant
  (T)/rs9923231 variant (T)`, CYP4F2 `*1/*3`, callSource MATCHER) and the application
  discards them (`TARGET_GENES`); every warfarin request returns Unknown
  (`capabilities.json`: explicit_abstention, dependencies CYP2C9 only).
- CPIC's own recommendation table has 0 warfarin rows (B1 snapshot). PharmCAT's jar
  has 12 CPIC warfarin rows, all with one text: "CPIC Guideline for
  Pharmacogenetics-Guided Warfarin Dosing: 2017 Update [Article: 28198005 ] recommends
  that pharmacogenetic warfarin dosing be accomplished through the use of one of the
  pharmacogenetic dosing algorithms, as summarized in Figure 2. See CPIC guideline
  annotation for details." In a real report the CPIC warfarin annotation is empty
  (no lookup key, no recommendation); only PharmCAT messages point to the flow chart.
  The report's DPWG and FDA annotations carry dose figures; they are not CPIC and are
  not used (standing rule 6).
- Positions (pinned positions VCF): VKORC1 1 (chr16:31096368, rs9923231 C>T); CYP4F2
  20 (chr19). The jar has no function or phenotype data for either gene.
  rs12777823 (CPIC's African-ancestry factor) is not in the positions VCF; it is a
  CYP2C9 `extraPosition` in PharmCAT's exemptions. This application collects no ancestry.

## Design

1. `TARGET_GENES` gains VKORC1 and CYP4F2; `position_requirements.json` gains both
   (positions regenerated by `scripts/build_position_requirements.py`), VKORC1 100% with
   its one position critical, CYP4F2 100% with the positions where PharmCAT's *3 differs
   from *1 critical (derived from the jar's definition file, recomputed by a test).
2. Warfarin: dependencies CYP2C9 + VKORC1; `guidance_capable` true. Label "Adjust
   Dosage" when both genes are sufficient on both evidence views (B3) and both are
   called; action = the CPIC text above, verbatim from the jar. No dose is computed or
   quoted. The result says ancestry is not collected, so rs12777823 and the
   African-ancestry branch of CPIC's flow chart are not assessed, and reports CYP4F2
   only as CPIC's optional modifier — it never changes the label.
3. Additive contract: per-gene findings for multi-gene results (gene, call, role,
   assessed), Pydantic and Dart together, rendered on the result card.
4. Coverage warnings name only genes a requested drug depends on (or its optional
   modifier), so files without chr16/chr19 rows do not gain two warnings on every
   non-warfarin request; `position_coverage` still lists every gene.

## Acceptance criteria (pre-committed)

| id | criterion |
|---|---|
| AC1 | VKORC1 and CYP4F2 are parsed and gated: `build_position_requirements.py --check` passes for every gene including them; VKORC1 critical = {31096368}; CYP4F2 critical = the *3-vs-*1 positions, recomputed from the jar by a test |
| AC2 | Warfarin is "Adjust Dosage" exactly when CYP2C9 and VKORC1 are both sufficient (both views) and called; its action text is the pinned CPIC text verbatim (a test asserts all 12 jar rows carry it); the serialized warfarin result contains no dose (no number followed by mg or %); it states that ancestry is not collected and that rs12777823 is not assessed; the label is identical with CYP4F2 absent, *1/*1 or a *3 carrier |
| AC3 | CYP2C9 or VKORC1 insufficient or uncalled → Unknown, the reason naming that gene |
| AC4 | The new contract field is read by Dart (`test_client_parity`) and a Dart widget test shows the VKORC1 and CYP4F2 rows for a warfarin result |
| AC5 | Through the real PharmCAT, synthetic VCFs (`generate_synthetic_vcf.py --from-jar`): (i) CYP2C9 *1/*1 + VKORC1 C/C → Adjust Dosage; (ii) *3/*3 + T/T + CYP4F2 *1/*3 → Adjust Dosage with CYP4F2 *1/*3 reported; (iii) VKORC1 row removed → Unknown naming VKORC1; (iv) CYP2C9 rows removed → Unknown naming CYP2C9 |

Zero-regression vs B4 (same application code as B3): S1–S6 6/6 labels; cohort 0
Unknown→confident and 0 other shifts (the cohort has no chr16 rows); 74 test VCFs 0
mismatches; A4 inputs 0 Unknown→confident. The only Unknown→confident changes allowed
are warfarin results with CYP2C9 and VKORC1 covered and called, justified by the CPIC
text in AC2.

Sabotage: (a) VKORC1 dropped from warfarin's dependencies → AC3/AC5(iii) red; (b) a dose
figure appended to the warfarin action → the no-dose test red; (c) Dart stops reading
the new field → parity red.

If a criterion fails, stop and report rather than adjust it.
