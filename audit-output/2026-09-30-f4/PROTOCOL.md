# F4 read-derived validation protocol, version 1

This protocol is to be frozen by `prepare.py freeze` after reference identity is verified and **before genotype calling or application scoring**. No production code or coverage threshold is changed. Research input preparation is not a production caller and is not clinical validation. No human or clinical review is claimed.

## Cohort and independent truth

The fixed two-person cohort is NA18526 (CYP2C19 `*1/*1`, normal control) and NA12878 (`*1/*2`, actionable control). Selection uses independent consensus truth and public 30× GRCh38 alignment availability, not read quality or application outputs. No failed individual will be replaced or omitted from the report. NA18526 was previously tested as an incomplete variant-only presentation; that prior result is known and is not represented as blinded. The current read-derived results have not been inspected at freeze.

Truth snapshot: CDC GeT-RM `Consolidated_PGx-HLA_table_1-22-25-V4.xlsx`, 22 January 2025 V4, downloaded from https://www.cdc.gov/lab-quality/media/files/2025/08/Consolidated_PGx-HLA_table_1-22-25-V4.xlsx; SHA-256 `c66174befa7a7bbb6cfaf174cc500a269565407807467204bd7bc6eaae3be109`. The preexisting extracted truth table is retained unchanged; snapshot and row hashes are captured at freeze. Truth is not used to generate any VCF genotype.

Phenotype and qualitative actionability are assigned independently using CPIC's 2022 CYP2C19/clopidogrel guideline, DOI `10.1002/cpt.2526`, PMID `35034351`, Tables 1–3: https://pmc.ncbi.nlm.nih.gov/articles/PMC9287492/. `*1/*1` maps to normal metabolizer; `*1/*2` to intermediate metabolizer. The primary guidance comparison is a **hypothetical ACS/PCI guideline context**, not an assertion that these reference donors have disease or need treatment. Normal metabolizer permits standard clopidogrel therapy if otherwise indicated; intermediate metabolizer warrants consideration of an alternative under the guideline. The application has no patient indication input; report that limitation and do not claim individualized treatment concordance. Non-ACS/non-PCI intermediate-metabolizer contexts have no CPIC recommendation and must not be generalized from the ACS/PCI comparison.

Only CYP2C19/clopidogrel is expected evaluable, conditional on all required evidence passing. No truth claims for NUDT15, paired TPMT/NUDT15, CYP2D6, structural variants, or other genes. Other five advertised drugs are requested as negative-scope checks and must abstain with this single-gene input.

Alignment: source header BWA 0.7.15-r1140, NYGC `GRCh38_full_analysis_set_plus_decoy_hla.fa`, duplicate marking and GATK PrintReads shown in preserved headers. ## Frozen preparation and quality rules

Caller: installed bcftools 1.24 / htslib 1.24, single-sample diploid multiallelic model, default mutation prior. Extraction: pysam 0.23.3 / samtools 1.21, isolated validation environment, not a backend dependency.

Target loci: **all 35** current CYP2C19 positions in `backend/app/data/position_requirements.json`; capture file hash and the complete ordered position list in frozen JSON. Extract one continuous chr10 interval from minimum required position minus 1,000 bp through maximum plus 1,000 bp. Call across this interval so neighboring indels are available, then normalize and select exact required start positions. Keep all duplicate records and let production's pessimistic duplicate-evidence rule apply. No trimming away a failing observation.

Read likelihood generation: `bcftools mpileup -q 20 -Q 20 -d 1000 --ns UNMAP,SECONDARY,QCFAIL,DUP,SUPPLEMENTARY -a FORMAT/DP,FORMAT/AD -f REF -r REGION -Ob -o PILEUP BAM`. Retain default BAQ and overlap handling; no anomalous-pair inclusion. This excludes low mapping/base quality, duplicates, secondary/supplementary/QC-failed/unmapped reads. These are validation preparation rules, not altered application requirements.

Calling: `bcftools call -m --ploidy 2 -a FORMAT/GQ -Ov -o CALLS PILEUP`. **Do not** pass variants-only, insert-missed, or constrained-allele options. Reference GT may only originate from this read-backed caller. Missing or no-call positions stay missing/no-call. Normalize with `bcftools norm -f REF -Ov -o NORMALIZED CALLS`; never split or force genotype phase. Exact required-site subsetting occurs afterward.

Every emitted required-site record must have complete diploid GT and per-sample DP >= 10. Variant calls additionally require caller GQ >= 20. Homozygous-reference calls require the original pileup PL likelihood margin for reference versus its best alternative >= 20; use the unmodified original pileup PLs because callers can omit GQ/alternative PLs on invariant output. This margin is **not** renamed GQ or treated as a calibrated error rate. Record actual GQ (including unavailable), original PLs, DP, AD, genotype, QUAL and FILTER. If caller GQ exists for a reference call it must also be >= 20. If no usable likelihood comparison exists, fail the record. Do not substitute QUAL for GQ.

Quality failures are retained with `FILTER=F4EvidenceFail`; passing observations get `PASS` only after these explicit upstream checks. The preparation may change FILTER and add provenance headers only; GT, REF, ALT, DP, GQ and AD are not invented or rewritten. No missing records are created. A failed or incomplete sample is still sent to coverage/analyze and reported as such. Production still requires 100% qualifying CYP2C19 positions.

## Evaluation and stopping rules

Freeze JSON + SHA-256 before extraction/calling; preserve command vectors, versions, timestamps and all intermediate evidence. Execute unmodified local `/coverage` and `/analyze` with real pinned PharmCAT 3.4.0 (data 2026-07-13), stored explanation eligibility unchanged. Request the six advertised drugs. Run direct PharmCAT separately and compare its report to the parser/API. Retain complete API results and explanation provenance. Exercise Dart model parsing and JSON export without UI changes where practical.

Compare exact unordered star diplotypes (whitespace only) first; report ambiguity/candidate containment separately, not as exact success. Genotype truth is consensus star-allele truth, not independent per-base truth at every target. Compare defining-variant read calls descriptively without claiming 35 independently validated genotypes. Existing known CYP2C19 *2 definition-version delta remains explicitly pinned; never patch a biological rule to force agreement.

Report completeness, independently expected versus observed diplotype/phenotype, guideline-direction concordance, and excluded pathways. Classify discrepancies as preparation/evidence insufficiency, nomenclature/version delta, caller/phase ambiguity, parser disagreement, application eligibility/label defect, or unresolved. **Stop before fixing a newly demonstrated production defect.** No post-result sample substitution, caller/threshold tuning, synthetic reference filling, or truth modification. Passing two controls does not establish population accuracy, clinical validity, or expert review.
